# 위험성평가 현장 사진 파일명 변경 스킬

## 목적

위험성평가 현장 사진을 실무에서 즉시 활용할 수 있도록 파일명을 표준 형식으로 자동 변경한다.

**출력 형식**: `촬영일시_촬영장소_기계및물질종류.확장자`

예시:
- `20240315_143022_제1공장_프레스기계.jpg`
- `20240315_150300_용접작업장_아세틸렌가스.png`
- `20240315_160000_화학물질창고_황산.jpg`

---

## 워크플로우

### Step 1: 입력 확인

사용자로부터 다음을 확인한다:
1. **처리 대상**: 단일 파일 경로 또는 폴더 경로
2. **촬영장소 정보**: 사용자가 직접 제공하거나, AI 이미지 분석으로 추론
3. **배치 처리 여부**: 폴더 내 모든 이미지 일괄 처리 여부

입력이 불명확하면 먼저 물어본다.

---

### Step 2: 파일 목록 수집

```python
# scripts/collect_files.py 참조
# 지원 확장자: jpg, jpeg, png, gif, bmp, tiff, webp, heic, heif
```

폴더가 주어진 경우: 해당 폴더의 이미지 파일 전체를 재귀적으로 수집한다.
단일 파일인 경우: 해당 파일 하나만 처리한다.

---

### Step 3: 메타데이터 추출 (촬영일시)

각 이미지에서 **EXIF 데이터**를 우선 추출한다.

```bash
python3 scripts/extract_exif.py <이미지경로>
```

**우선순위**:
1. EXIF `DateTimeOriginal` (촬영 원본 시각) → 형식: `YYYYMMDD_HHMMSS`
2. EXIF `DateTime` (파일 수정 시각)
3. 파일 시스템 `mtime` (최후 수단)
4. EXIF 없으면 → `촬영일시미상` 사용 후 사용자에게 알림

---

### Step 4: AI 이미지 분석 (촬영장소 + 기계및물질종류)

사용자가 촬영장소와 기계/물질 정보를 **직접 제공한 경우** → 그대로 사용  
제공하지 않은 경우 → `scripts/analyze_image.py`를 실행하여 AI가 이미지를 분석한다.

```bash
python3 scripts/analyze_image.py <이미지경로>
```

AI 분석 프롬프트 방향:
- **촬영장소**: 공장 구역, 작업장 명칭, 창고, 사무실 등 (예: 제1공장, 용접작업장, 원자재창고)
- **기계및물질종류**: 구체적인 기계명 또는 화학물질명 (예: 프레스기계, LPG가스, 황산, 컨베이어벨트)
- 불명확할 경우 가장 가능성 높은 항목으로 추정하고 `_추정` 접미사 추가

---

### Step 5: 파일명 생성 규칙

```
{YYYYMMDD_HHMMSS}_{촬영장소}_{기계및물질종류}{.확장자}
```

**정제 규칙** (파일명 안전 처리):
- 공백 → 제거 (붙여쓰기)
- 특수문자 (`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`) → 제거
- 괄호류 → 제거
- 최대 길이: 각 필드 20자 이내로 truncate
- 확장자: 원본 그대로 유지 (소문자로 통일)

**중복 파일명 처리**:
- 동일 파일명 존재 시 `_01`, `_02` 순번 추가

예시:
| 원본 | 변환 후 |
|------|---------|
| `IMG_2034.jpg` | `20240315_143022_제1공장_프레스기계.jpg` |
| `DSC_0042.jpeg` | `20240315_150300_용접작업장_아세틸렌가스.jpeg` |
| `photo.png` | `촬영일시미상_화학물질창고_황산.png` |

---

### Step 6: 실행 전 미리보기 및 확인

**반드시** 실제 변경 전에 변경 목록을 표 형식으로 사용자에게 보여준다.

```
변경 예정 목록:
┌──────────────────────┬─────────────────────────────────────────────┐
│ 원본 파일명          │ 변경될 파일명                               │
├──────────────────────┼─────────────────────────────────────────────┤
│ IMG_2034.jpg         │ 20240315_143022_제1공장_프레스기계.jpg      │
│ DSC_0042.jpeg        │ 20240315_150300_용접작업장_아세틸렌가스.jpeg│
└──────────────────────┴─────────────────────────────────────────────┘
총 2개 파일. 진행하시겠습니까?
```

사용자 승인 후 실제 파일명 변경을 실행한다.

---

### Step 7: 파일명 변경 실행

```bash
python3 scripts/rename_files.py <매핑JSON경로>
```

- 원본 파일은 별도 백업 폴더(`_원본백업_YYYYMMDD`)에 복사 후 변경 진행
- 변경 결과 로그를 `rename_log_YYYYMMDD_HHMMSS.txt`로 저장

---

### Step 8: 결과 보고

완료 후 다음 형식으로 보고:

```
✅ 파일명 변경 완료
- 처리 완료: N개
- 오류 발생: N개 (있을 경우 목록 표시)
- 백업 위치: <경로>/_원본백업_YYYYMMDD/
- 로그 파일: rename_log_YYYYMMDD_HHMMSS.txt
```

---

## 스크립트 참조

상세 구현은 `scripts/` 폴더의 각 파이썬 스크립트를 참조한다:

| 파일 | 역할 |
|------|------|
| `collect_files.py` | 이미지 파일 목록 수집 |
| `extract_exif.py` | EXIF 메타데이터 추출 |
| `analyze_image.py` | AI 이미지 분석 (촬영장소/기계물질) |
| `rename_files.py` | 실제 파일명 변경 및 백업 |

---

## 주의사항

- 파일명 변경은 **되돌리기 어려우므로** 반드시 미리보기 확인 단계를 거친다
- HEIC/HEIF 형식(아이폰 촬영)은 `pillow-heif` 패키지 필요
- AI 분석 결과가 불확실한 경우 사용자에게 직접 입력을 요청한다
- 동일 현장의 대량 사진인 경우 촬영장소와 기계/물질을 한 번만 입력받아 일괄 적용할 수 있다
