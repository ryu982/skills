# PPT 디자인 지침 (비즈니스 템플릿 분석 기반)

미리캔버스 인기 비즈니스 프레젠테이션 템플릿(제안서·보고서·IR·기획서·교육자료) 수백 종의 공통 패턴을 정리한 제작 기준이다. "노무법인 청인" 스타일 요청 시에는 cheong-in-ppt 스킬이 우선하며, 이 지침은 레이아웃·구성 보완용으로만 쓴다.

## 0. 조직 고정 규칙 (최우선)

- 타이틀, 글상자, 표 제목에 흰색 글자 금지.
- 표 제목(헤더) 배경: 연한 베이지(#F3EBDD), 연한 연두(#E6F2D9), 하늘색(#DCEBF7), 주황(#FBE3CC) 중 택1, 글자는 진한 네이비/차콜.
- 따라서 템플릿에 흔한 "진한 배경 + 흰 글씨" 표지는 쓰지 않는다. 진한 색은 띠·도형·포인트 블록으로만 쓰고, 텍스트는 밝은 배경 위에 진한 색으로 둔다.

## 1. 전체 톤

- 16:9, 여백 넉넉(좌우 최소 6~8%), 요소 수 적게. "심플하고 깔끔한"이 공통 키워드.
- 한 슬라이드 = 한 메시지. 본문 텍스트는 3~5줄 이내, 나머지는 도식·표·아이콘으로.
- 장식은 1종만(얇은 선, 반투명 원, 그라데이션 블롭, 사선 블록 중 하나).

## 2. 컬러 시스템

주색 1 + 보조 1 + 무채색. 템플릿에서 가장 많이 쓰인 조합:

| 계열 | 주색 | 보조/포인트 | 용도 |
|---|---|---|---|
| 신뢰 블루(최다) | #1F4FD8 / 네이비 #14234B | 하늘 #DCEBF7 | 제안서·노무자문 기본값 |
| 딥블루+그라데이션 | #2B3A8F → #6C63FF | 연보라 #EEEAFE | IR·전략 |
| 틸/그린 | #0F7C7A | 민트 #E3F4F1 | 교육·ESG·안전보건 |
| 레드/오렌지 포인트 | #E8452C / #F26B1D | 베이지 #FFF4EC | 강조 1곳만, 경고·리스크 |
| 모노+라임 | 차콜 #222 | 라임 #C6F432 | 트렌디 교육자료 |

- 강조색은 슬라이드당 1~2곳(핵심 숫자, 키워드 한 단어)에만.
- 배경은 흰색 또는 아주 연한 회색(#F5F6F8)·연한 블루(#F2F6FC).

## 3. 타이포그래피

- 한글: Pretendard / Noto Sans KR (없으면 맑은 고딕). 굵기 대비로 위계를 만든다(ExtraBold 제목 vs Regular 본문).
- 표지 제목: 2줄 구성이 정석 → 1줄 "수식어"(얇게, 회색/주색) + 2줄 "핵심명사"(굵게, 크게). 예: "심플하고 깔끔한 / 비즈니스 제안서", "필수 페이지만 담은 / 프로젝트 제안서".
- 제목 일부 단어만 주색으로 컬러링(예: "프로젝트 **완료** 보고서").
- 영문 병기: 소제목 위 작은 대문자 라벨(BUSINESS PROPOSAL, 2026 REPORT) 자간 넓게.
- 크기 기준: 표지 44~60pt / 장 제목 28~32pt / 본문 14~18pt / 캡션 10~11pt.

## 4. 표지 레이아웃 패턴 (택1)

1. **좌측 정렬 텍스트 + 우측 이미지**: 우측 40~50%에 건물·사무실·업무 사진(흑백 또는 블루톤). 가장 흔함.
2. **중앙 정렬 + 프레임**: 얇은 테두리/브라우저창 모양 프레임 안에 중앙 제목. 미니멀.
3. **사선·기하 블록**: 한쪽 모서리에 주색 사선/삼각 블록, 나머지 흰 배경.
4. **그라데이션 블롭**: 연한 그라데이션 원·물결을 배경 장식으로, 텍스트는 진한 색.
5. **상단 소형 로고 + 하단 정보바**: 좌상단 회사 로고, 하단에 얇은 선과 발표자·날짜·연락처를 한 줄로.

공통 요소: 좌상단 로고/회사명(작게), 하단 날짜·발표자·소속, 상단 작은 라벨 태그(둥근 pill 형태).

## 5. 본문 슬라이드 구성

- 상단: 장 번호(01, 02…) + 장 제목 + 얇은 구분선. 우상단에 섹션명 작게.
- 하단: 페이지 번호, 회사명(푸터) 일관 유지.
- 자주 쓰이는 본문 유형:
  - 목차: 번호 크게(01~05) + 항목명, 좌측 세로 정렬 또는 2열.
  - 3~4단 카드: 아이콘 + 소제목 + 2줄 설명, 카드 배경 연한 색, 모서리 라운드 8~12px.
  - 프로세스: 가로 화살표/쉐브론 4~6단계, 단계 번호 원형 배지.
  - 비교표: 헤더 연한 색 배경(0번 규칙), 행 구분은 얇은 회색 선, 세로선 생략.
  - 핵심 수치: 큰 숫자(48pt+) + 단위 + 한 줄 설명, 3개 나란히.
  - 타임라인/로드맵: 가로 선 위 점, 위아래 교차 텍스트.
  - 조직도·RACI: 박스는 라운드, 선은 1pt 회색.
- 사진은 한 장을 크게(반 화면 이상) 쓰고, 작은 사진 여러 장 나열은 피한다.

## 6. 문서 유형별 기본 구성

- **자문/컨설팅 제안서**: 표지 → 목차 → 회사소개 → 현황진단 → 제안내용 → 수행방법·일정 → 수행조직 → 비용 → 기대효과 → 마무리(Thank you + 연락처)
- **결과 보고서**: 표지 → 요약(핵심 수치 3개) → 배경·목적 → 분석결과 → 개선방안 → 향후계획
- **교육자료**: 표지 → 학습목표 → 본론(장별 간지) → 사례 → 퀴즈/체크리스트 → 요약
- **IR/사업계획**: 문제 → 해결책 → 시장 → 비즈니스모델 → 실적·계획 → 팀 → 투자요청

장이 3개 이상이면 간지(섹션 디바이더) 슬라이드 삽입: 큰 장번호 + 장 제목, 주색 블록 1개.

## 7. 제작 체크리스트

- [ ] 흰색 글자 타이틀·글상자·표 제목 없음
- [ ] 표 헤더 연한 베이지/연두/하늘/주황
- [ ] 주색 1 + 보조 1 이내
- [ ] 슬라이드당 메시지 1개, 본문 5줄 이내
- [ ] 로고·푸터·페이지번호 위치 전 슬라이드 동일
- [ ] 폰트 2종 이하, 굵기로 위계
- [ ] 수치·법령 인용은 출처 표기(법령은 korean-law 스킬로 검증)
